# Basemap data

`osm-locality.geojson` is an extract of OpenStreetMap data (roads, waterways, water bodies, place names)
for the demo locality plan, fetched with `scripts/fetch_osm_basemap.py` from the Overpass API and cached
here so builds and CI run offline.

https://www.openstreetmap.org/copyright and https://opendatacommons.org/licenses/odbl/1-0/

The extract is a Derivative Database under ODbL; it is distributed under ODbL 1.0 (not the repository's
code licence). Every sheet that shows it carries the attribution "© OpenStreetMap contributors".
OSM is not survey data and is shown for location only.
